\# ♟️ Chess AI — Python \& Pygame



A desktop chess game built using Python and Pygame, featuring Player vs Player and Player vs Computer gameplay.



\## ✨ Features



\- 👥 \*\*Player vs Player\*\* — Play chess with another person on the same computer.

\- 🤖 \*\*Player vs Computer\*\* — Challenge the built-in chess AI.

\- 🎚️ \*\*Adjustable Difficulty\*\* — Easy, Medium, Hard, and Expert levels.

\- 🧠 \*\*Chess AI\*\* — Search-based move selection with position evaluation.

\- ⏳ \*\*Natural Thinking Delays\*\* — The computer takes time to consider its moves.

\- 🎨 \*\*Enhanced Graphics\*\* — A modern chessboard interface with move highlights.

\- 🔄 \*\*Restart Game\*\* — Start a new game whenever you want.



\## 🛠️ Built With



\- Python

\- Pygame CE

\- python-chess



\## 📋 Requirements



\- Python 3.10 or newer recommended

\- pygame-ce

\- python-chess



\## 🚀 Installation



\### 1. Clone this repository



```bash

git clone https://github.com/Vinit-Kumar01/CHESS.git

cd CHESS

```



\### 2. Install dependencies



```bash

python -m pip install -r requirements.txt

```



\### 3. Run the game



```bash

python main.py

```



\## 🎮 Game Modes



\*\*Player vs Player:\*\* Play against another player locally.



\*\*Player vs Computer:\*\* Play against the computer and choose your preferred difficulty.



\## ⌨️ Controls



Use the in-game controls to select game modes and difficulty. The current version also supports keyboard shortcuts for certain actions.
